# Symbion 中国区官网

静态站点，可直接导入 [Vercel](https://vercel.com) 或 v0 改设计。

## 导入 Vercel

1. 把整个 `website` 文件夹拖到 [vercel.com/new](https://vercel.com/new)
2. Framework Preset 选 **Other**（不要选 Next.js）
3. 部署后首页就是 `index.html`

或在本目录执行：

```bash
npx vercel
```

## 目录

- `index.html` 首页
- `login.html` 登录
- `css/` `js/` 样式与交互（含本地 GSAP）
- `assets/` 字体、双手图、纹理
- `product/` `explore/` `company/` `resources/` `legal/` 内页
