# Ice Home Preview

Standalone recolor of the H2-B welcome screen using Symbion marketing **ice blue** (`#3a8fb8` / `#74c1e6` family).

- Does **not** modify `symbion-web` or the live H2-B prototype.
- Open locally: serve `website/` and visit `/ice-home/`
- Live (after push): https://lulu2467.github.io/symbion-site/ice-home/

Rebuild from source:

```bash
python _inject_ice.py
```
